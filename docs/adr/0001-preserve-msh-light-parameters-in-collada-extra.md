# Preserve MSH light parameters in COLLADA extra metadata

Static MSH light parameters are raw floats whose game-facing meanings are not confirmed, so EarthTool does not present them as COLLADA color. Exported active lights use white standard color and preserve the complete MSH-specific light record with unqualified, named, invariant round-trip values in `<technique profile="EARTHTOOL"><msh_static_light version="1">...</msh_static_light></technique>`; imports use standard COLLADA fields only when this metadata is absent. The payload includes a source number from 1 through 4 that must agree with the light name; conflicts, duplicates, unsupported versions, and malformed payloads are import errors. Inactive records are omitted because their corresponding attachment declares them absent, even when converter recentering left nonzero storage behind.
